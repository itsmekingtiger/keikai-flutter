Key KkGrid's stagger scope so a keyed child keeps its state

With stagger on, KkGrid puts a child that is not a KkCell inside a stagger scope, which hid the child's key from the grid. The scopes were matched by position, so when the list was reordered, or a child was added or removed before it, a keyed child was disposed and built again and lost its state. The scope now carries a key made from the child's key and moves with its child; the child's own key still finds the child alone, and a global key is still used only once.
